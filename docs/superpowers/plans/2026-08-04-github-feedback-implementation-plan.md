# GitHub 识别反馈实施计划

## 目标

为每条扫描结果提供可见的反馈入口，生成最小化、可预览、可本地留存的脱敏报告，并打开 GitHub Issue Form 供用户主动提交。公开 Issue 不参与客户端实时判定。

## 实施步骤

1. 在数据目录增加 `feedback` 子目录，保存 Markdown 与 JSON 两份脱敏反馈。
2. 新增反馈报告模型、允许字段构造、敏感信息替换、可选 SHA256 和脱敏自测。
3. 在结果表增加“反馈”按钮列，选中单条结果后打开反馈预览窗口。
4. 窗口支持反馈类型、用户预期、可选 SHA256、复制内容、仅本地保存和打开 GitHub。
5. 增加 `.github/ISSUE_TEMPLATE/recognition-feedback.yml`，收集结构化识别反馈。
6. README 补充使用方式、隐私边界和维护闭环。
7. 运行脱敏自测、身份碰撞烟测、完整扫描烟测、普通构建和差异检查。

## 回滚

删除新增反馈源码与 Issue Form，移除主窗体反馈列、反馈目录属性及命令行自测入口即可；不涉及注册表、服务、计划任务或既有数据迁移。
