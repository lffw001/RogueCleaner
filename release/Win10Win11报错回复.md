# Win10/Win11 扫描失败回复

当前 `v2.0.13` 是 C# WinForms 单 EXE，正常运行不依赖外部 PowerShell 脚本和规则目录，也不再提供自解压一键运行版；首次运行不会再提示创建桌面快捷方式。

当前新版如果扫描阶段异常，会在 `流氓软件克星数据\reports` 下写入 `scan-error-*.json` 失败报告；正常扫描则写入 `scan-*.json`。反馈时请优先带这个报告，不要只截图“退出码1”。

如果仍然出现“扫描失败”或类似报错，请先确认：

1. 下载的是 `RogueCleaner-v2.0.13-*.exe` 直出 EXE。
2. 文件 SHA256 能对上 `SHA256SUMS-v2.0.13-*.txt`。
3. 不要从浏览器下载面板、压缩包预览窗口或聊天软件临时目录里运行。
4. 把 EXE 放到桌面或普通文件夹后再运行。
5. 涉及服务、计划任务、HKLM 项目时，用界面里的“管理员模式”重新打开。

如果按以上方式仍然失败，请反馈：

- Windows 版本
- 是否管理员运行
- 工具版本
- EXE 文件名和 SHA256
- `流氓软件克星数据\logs` 里的错误日志
- `流氓软件克星数据\reports` 里的扫描报告
- 如果存在，带 `流氓软件克星数据\reports\scan-error-*.json`
