# 恢复记录清理与全中文显示实施计划

1. 在清理引擎中增加批次时间解析、占用空间统计、旧批次筛选、受限路径删除及同批次报告删除。
2. 在恢复中心增加“删除当前批次”和“清理旧记录”按钮、预览确认、操作结果与空状态刷新。
3. 增加统一的用户显示文本转换，覆盖恢复状态、右键菜单类型、已知英文菜单标题和 Windows 系统快捷菜单名称。
4. 将可验证身份的 Windows 打包第三方右键扩展合并进普通右键管理，并固定主表表头和内容居中。
5. 扩展界面/右键冒烟回归，使用临时模拟数据验证保留策略、路径保护、删除回读、中文显示和打包扩展枚举。
6. 构建验证版并运行安全冒烟；再构建正式单文件程序并执行正式安全冒烟。
