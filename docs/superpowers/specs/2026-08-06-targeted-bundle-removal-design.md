# 附带产品定向卸载与常驻治理设计

## 目标

保留用户主动安装的主程序，只处理它额外安装的独立产品或异常持久化入口，杜绝“发现一个附带组件就卸载整个厂商软件”。

该模型是全厂商统一规则，不为搜狗、360 或其他单一厂商设置例外分支。

## 分层动作

1. 来源主程序：不进入卸载结果。
2. 独立附带产品：确认独立产品名、卸载项和附带产品特征后，允许单独打开其卸载器。
3. 后台服务与计划任务：只禁用命中的具体服务或任务，并进入恢复中心。
4. 启动项、右键和资源管理器入口：只处理对应注册表入口。
5. 运行进程：没有可验证持久化来源时只提示，不强杀。
6. 身份或产品边界不清：只提示，不打开卸载器。

## 执行保护

扫描结果保存预期产品名、发布者和卸载命令。用户执行时重新读取卸载注册表项，三项完全一致后才启动卸载器；变化时拒绝并要求重新扫描。

## 验证

- 纯规则回归覆盖搜狗输入法、360 安全卫士、WPS、百度网盘、微信、普通浏览器、独立桌面/壁纸/热点/游戏产品和无独立卸载项的弹窗组件。
- 当前系统只读扫描确认搜狗输入法主体不再出现“打开卸载/定向卸载”。
- 身份、扫描和 UI 回归通过后构建正式程序。
