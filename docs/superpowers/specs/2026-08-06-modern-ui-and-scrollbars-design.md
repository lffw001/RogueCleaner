# 现代化统一界面与滚动条设计

## 问题

当前主界面、右键管理和恢复中心存在三套不同视觉语言。大量数据使用 Windows 原生细滚动条，数据达到数百或上千项时滑块过短、难以发现和拖动；工具栏混用老式系统图标，表格、卡片、标题和按钮也缺少统一层级。

## 设计方向

采用成熟安全工具的轻量框架：浅灰蓝画布、白色内容面、青绿色主色、深蓝灰正文。借鉴火绒的克制留白、软件 Logo 优先和清晰筛选层级，以及 360 的单一强主操作和功能入口辨识度；不复制其商标、图标或品牌素材。危险操作才使用红色，提示和次要内容降低饱和度。保留系统窗口边框、高 DPI 和键盘操作能力，不采用无边框全自绘窗口。

主界面只允许“开始扫描”成为强视觉按钮。四项统计改为高度约 54 像素的紧凑状态带，数字、名称、说明横向组织，不再占用大面积空白。导航与工具栏禁止使用 Unicode 字符冒充图标，全部改为同一笔画、尺寸和颜色体系的线性图标。

## 统一组件

### 滚动条

- 为所有主要 DataGridView 使用项目内自绘垂直滚动条。
- 轨道宽度 16 像素，可拖动滑块宽度 10 像素。
- 滑块最小高度 42 像素，确保 1600 项列表仍清晰可见。
- 默认、悬停和拖动状态使用三档颜色；支持点击轨道翻页、拖动和鼠标滚轮同步。
- 内容不需要滚动时自动隐藏滚动条并把宽度归还表格。
- 原生表格滚动行为、选中项、键盘导航及鼠标滚轮保持不变。

### 表格

- 统一 36 像素行高、38 像素表头、浅色表头和隔行底色。
- 统一选中颜色、边框、字体、单行省略和工具提示。
- 软件图标继续保持统一尺寸，风险颜色和失败状态格式不被主题覆盖。

### 卡片与按钮

- 卡片使用 8 像素圆角、细边框和轻量层次，不增加厚重阴影。
- 主按钮、描边按钮、顶部按钮和工具按钮统一 6 像素圆角。
- 工具按钮不再显示旧式 Windows 系统图标，也不使用圆圈字符图标，改用主题内绘制的 18/20 像素线性动作图标。
- 危险操作保持红色，普通工具保持中性色，主要动作使用青绿色。

### 窗体一致性

- 主界面、右键管理、专用模块、高级兼容、恢复中心、反馈、关于和编辑窗体统一字体、画布、输入控件和表格主题。
- 恢复中心的大面积深绿色标题改为与主界面一致的白色轻标题区，仅保留主色版本标识和底部强调线。
- 现有布局与功能入口不重排，避免用户重新学习；本次只统一视觉层级和滚动体验。

## 验证

- UI 冒烟测试覆盖默认尺寸、最小尺寸、125%/150%/200% 缩放和所有主要窗体。
- 新增滚动条回归：主表格和右键管理表格必须挂载现代滚动条，宽度不小于 16 像素，最小滑块高度不小于 42 像素。
- 保持身份、扫描、反馈、恢复和右键模块现有冒烟测试全部通过。
