这次有两个问题：

1. Win10 管理员启动后“扫描失败，退出码 1”

   原因是部分 Win10/Win11 电脑没有 PowerShell 7，程序会使用系统自带 Windows PowerShell 5.1。旧版透明包里的 `RogueCleaner.ps1` 是 UTF-8 无 BOM，PowerShell 5.1 会按 ANSI 读取中文脚本，导致脚本被读坏后直接语法错误。

   新版已把发布包里的 `RogueCleaner.ps1` 改成 UTF-8 BOM，并修复了个别非法路径拖垮扫描的问题。

2. Win11 提示“缺少文件”

   透明发布版不是单文件程序，exe 旁边必须保留 `RogueCleaner.ps1` 和 `rules` 目录。不要在 WinRAR/压缩包预览窗口里直接双击 exe，也不要只把 exe 单独拖出来运行。

   正确方式：先完整解压整个文件夹，再运行解压后文件夹里的 `流氓软件克星.exe`。

   如果只想双击一个文件运行，请下载新版 `流氓软件克星_一键运行版_20260720-200304.exe`。

新版已重新打包，并加入了更明确的缺文件提示和 `先解压整个文件夹再运行.txt`。
