# 权限与管理员重启统一规范

本规范适用于总览、启动项管理、右键管理、弹窗/流氓诊断、恢复中心及后续新增功能。

## 权限模型

- 应用清单固定使用 `asInvoker`，不得改成每次启动都强制管理员权限。
- 普通模式必须允许扫描、查看结果、管理当前用户范围项目和导出证据报告。
- 只有写入 HKLM、服务、系统计划任务、所有用户右键菜单或恢复同类系统项目时，才通过 Windows `runas` 请求 UAC。
- 禁止使用服务、计划任务、注册表劫持、UAC 绕过或永久修改 ACL 实现静默提权。

## 用户反馈

- 用户取消 UAC、没有管理员凭据或被单位策略拒绝时，程序不得退出或崩溃；应说明普通模式仍可使用。
- 系统级项目必须在详情提示“处理时需要管理员权限”，但仍允许用户扫描和生成报告。
- 管理员权限由 Windows 或组织管理员授予，程序不得宣称能够绕过系统策略。

## 状态恢复

- 提权前将页面、恢复批次和待处理项目的稳定目标标识写入数据目录的短期状态文件。
- 状态文件仅允许从本程序 `state` 目录读取，十分钟后失效，消费后立即删除。
- 管理员进程重新扫描后恢复勾选，但不得自动清理、自动删除或自动恢复，最终操作仍由用户确认。

## 回归要求

- 身份回归必须验证同一目标的稳定标识一致、不同目标不冲突。
- 必须验证提权状态写入、读取、消费删除以及目录边界。
- UI 回归必须确认普通模式按钮显示“请求管理员权限”，管理员模式显示“管理员模式”。
