# 全项目软件图标与右键管理小白化实施计划

## 阶段 1：公共基础

1. 新增 `SoftwarePresentation.cs`，实现统一窗体 ICO、未知/Windows 回退图标、命令/图标字符串路径解析、服务注册表只读解析、CLSID 文件解析和缓存。
2. 为 `Finding`、`ContextMenuEntry`、`SpecialMenuEntry`、`AdvancedMenuEntry`、`CleanupResult` 增加不参与 JSON 序列化的 UI 图标字段和可读来源字段。
3. 增加验证构建回归，覆盖 EXE 图标、带参数命令、服务 `ImagePath` 模拟、CLSID 模拟、缺失文件和缓存命中。

## 阶段 2：全窗体统一 ICO

1. 用 `UiTheme.ApplyWindowIdentity(Form)` 替代主窗体和恢复中心的重复代码。
2. 在其余八个子窗体构造阶段统一调用。
3. UI smoke 枚举所有窗体，比较图标句柄/尺寸并记录缺失。

## 阶段 3：各列表图标接入

1. 主扫描表格增加软件图标列，扫描完成后后台分批解析并逐行刷新。
2. 右键基础、专用、高级模块增加图标与“关联软件”字段。
3. 恢复中心增加图标列，根据清理结果目标解析。
4. 所有解析使用共享缓存和取消/窗体销毁保护，不重绑整表。

## 阶段 4：右键管理 A 版

1. 将标题、说明、场景导航、搜索筛选、紧凑工具栏、列表和详情面板分为独立行。
2. 建立技术场景到人话场景的集中映射。
3. 将专用/高级能力合并到场景导航；保留原窗体作为具体管理页或弹出页。
4. 主列表替换为图标、显示状态、菜单名称、出现时机、关联软件和建议。
5. 技术详情折叠显示，复制/定位注册表移入“更多工具”。

## 阶段 5：验证

1. 编译验证版并运行身份、权限、右键基础、专用、高级、UI 和图标回归。
2. 编译正式版并运行扫描、身份、反馈和 UI 回归。
3. 使用真实桌面窗口检查所有窗体 ICO、A 版布局、工具栏尺寸、图标逐批出现、搜索与鼠标响应。
4. 检查无 WMI 服务创建/修改代码、无测试注册表/服务/任务残留、无 `.superpowers` 设计会话进入 Git。

## 交付边界

本轮只进行本地修改与验证，不自动更新版本号、提交、推送或创建 Release；这些动作仍等待明确发布指令。
