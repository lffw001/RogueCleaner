# 全项目中文展示设计

## 目标

用户可见的功能语义全部使用中文，同时保留第三方品牌识别度和技术证据，不修改注册表中的原始菜单文字。

## 设计

1. `ChineseDisplayText` 是唯一展示本地化入口，负责菜单操作句、软件名称和安全回退。
2. 枚举阶段先翻译注册表静态标题；软件身份解析完成后补充中文用途；动态标题探针完成后再次翻译。
3. 能可靠理解的英文操作句转换为中文，例如“Edit with PyCharm”显示为“使用 PyCharm 编辑”。
4. 不能可靠理解的标题按已确认软件显示为“软件名 + 右键菜单”，来源未知时按出现位置生成中性中文名称。
5. 原始英文名称、命令、路径和组件编号仅在技术详情中保留。

## 验证

- 单元回归覆盖已知翻译、通用英文句式和未知英文回退。
- UI 回归等待软件身份解析结束后，检查每一行菜单名和软件名均包含中文语义。
- 身份、扫描和 UI 冒烟测试通过后再构建正式程序。
