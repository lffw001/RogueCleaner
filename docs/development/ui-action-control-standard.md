# 操作按钮与工具栏统一规范

本规范适用于总览、启动项管理、右键管理、弹窗/流氓诊断、恢复中心及以后新增的所有窗体。

## 唯一实现入口

- 业务窗体不得再自行设置按钮的颜色、边框、圆角、字体和图标。
- 普通操作统一调用 `UiTheme.ActionButton`，首页主操作也沿用相同的圆角、字号、图标尺寸和交互状态。
- 按钮按语义选择角色：`Primary` 主操作、`Standard` 普通操作、`Warning` 谨慎操作、`Danger` 删除操作、`Close` 关闭操作。
- 危险色只用于删除、永久清理等不可直接撤销的动作；恢复、刷新不能使用危险色。

## 尺寸与布局

- 标准按钮高 36 像素，最小宽度 104 像素，图标 18 像素，圆角半径 6～7 像素。
- 同一工具栏按钮必须等高、同一基线、统一左右间距。
- 工具按钮必须单独占一行，不得混入标题、说明、位置选择或搜索区域。
- 标题区只展示模块名称、说明和状态，不放置突兀的大号操作按钮。
- 窗口缩放后允许工具栏横向滚动，但不得压缩到文字或图标显示不全。

## 回归要求

- UI 自动检查必须确认关键按钮可见、角色标记正确且高度一致。
- 新窗体若出现私有按钮样式函数，视为规范回退，合入前必须改为调用 `UiTheme.ActionButton`。

## 滚动交互

- 使用自定义滚动条的列表、详情面板和恢复记录必须由 `UiTheme` 公共滚动组件统一接管鼠标滚轮，业务窗体不得另写滚轮事件。
- 鼠标悬停在列表内容、详情卡片或自定义滚动条上时都必须可以直接滚动，不要求用户先点击滚动条。
- 下拉框、数字输入框和可独立滚动的文本框保留自身滚轮行为，不得被父级详情面板抢占。
- UI 自动检查必须分别验证扫描结果表、详情面板和恢复中心列表能够通过一个标准滚轮刻度向下滚动。
