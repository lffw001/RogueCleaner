# 全项目中文展示规范

本规范适用于总览、启动项管理、右键管理、弹窗/流氓诊断、恢复中心以及以后新增的所有窗体。

## 展示原则

- 程序自身的标题、按钮、状态、类型、说明和错误提示必须使用中文。
- 第三方右键菜单的英文操作句必须经 `ChineseDisplayText` 统一转换，不得直接进入主列表。
- 软件品牌属于专有名称，可以保留 `PyCharm`、`Notepad++`、`WinRAR` 等原名，但必须补充中文用途，例如“PyCharm 开发工具”“WinRAR 压缩软件”。
- 无可靠译文时显示“软件名 + 右键菜单”；连软件来源也无法确认时显示“对应场景 + 右键菜单”，不得编造具体功能。
- 路径、命令、CLSID、注册表位置和第三方原始名称属于证据，允许保留原文，但只能放在“技术详情”区域。

## 唯一实现入口

- 菜单标题统一调用 `ChineseDisplayText.ContextMenuName` 和 `EnsureChineseContextMenuName`。
- 软件名称统一调用 `ChineseDisplayText.SoftwareName`。
- 动态右键标题探针返回结果后必须再次经过中文展示层，不能覆盖为英文。
- 业务窗体不得私自维护另一份英文到中文映射表。

## 回归要求

- 固定覆盖 PyCharm、Notepad++、WPS、WinRAR、Beyond Compare 等代表项目。
- UI 回归在右键管理逐行检查：菜单名称和关联软件列必须包含中文语义。
- 原始英文名称必须仍能在技术详情中查看，确保排查和反馈时证据不丢失。
