# 安全工具控制台 UI 改版实施计划

1. 新增 WinForms 主题辅助类，集中管理颜色、字体、按钮、卡片、状态标签和无闪烁表格。
2. 将主窗体改为标题栏、命令栏、左侧导航、状态卡片、结果表、右侧详情和底部状态栏结构。
3. 保留现有按钮事件与扫描数据绑定，补充导航筛选、行选择详情更新和详情复制功能。
4. 将反馈入口固定到“检查更新”之后，移除依赖横向滚动的表格反馈列。
5. 重做反馈窗体视觉层级，不修改脱敏、落盘和 GitHub 打开逻辑。
6. 编译普通版，运行反馈、身份、扫描烟测与清理/恢复验收，再恢复普通发布构建。
7. 检查最小窗口、默认窗口、高 DPI 控件边界和最终 EXE 哈希。

回滚仅需移除主题辅助文件，并恢复主窗体和反馈窗体布局代码；不涉及系统设置或业务数据迁移。
