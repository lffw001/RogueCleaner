# 扫描后顶部工具栏遮挡修复设计

## 问题

主窗口顶部工具区固定为 88px，同时把操作按钮、搜索标签和搜索框放在允许自动换行、自动滚动的同一个 `FlowLayoutPanel` 中。窗口宽度不足以容纳全部控件时，搜索控件会换到第二排；扫描期间进度条占用底部空间后，工具区高度不足，流式面板出现纵向滚动并可能保留滚动偏移，导致第一排按钮被裁切。

## 设计

- 将顶部工具区改为三个职责明确的固定布局行：操作按钮、搜索控件、扫描进度条。
- 第一排仅放八个操作按钮，继续允许在极端窄窗口或高缩放环境下换行，但不启用纵向自动滚动。
- 第二排固定放“搜索”标签和搜索框，不再参与按钮流式换行。
- 第三排只放扫描进度条；进度条显示或隐藏不能改变前两排的位置。
- 相应增加顶部工具区高度，保持现有颜色、按钮文字、功能和结果表格行为不变。

## 验收标准

1. 程序启动后，八个操作按钮完整可见，搜索框位于独立第二排。
2. 点击“开始扫描”后，进度条显示时按钮和搜索框不移动、不裁切。
3. 扫描完成并加载结果后，顶部控件仍完整可见，无纵向滚动条或残留滚动偏移。
4. 最小窗口尺寸和当前 DPI 缩放下无控件重叠；结果表格仍可正常使用横向滚动。
5. 项目能够重新编译，`--scan-smoke` 通过。

## 变更范围

仅修改 `src/v2/RogueCleanerV2.cs` 的主窗口顶部布局。保留现有扫描、清理、恢复、搜索和更新逻辑，不改版本号，不提交、不发布。
