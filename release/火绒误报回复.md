# 关于火绒/其它杀软提示风险

当前 `v2.0.13` 已经改成 C# WinForms 单 EXE：

- 不加壳
- 不混淆
- 不内嵌 PowerShell 脚本
- 不释放隐藏 payload
- 不做自解压一键运行版
- 不创建桌面快捷方式
- 不常驻后台
- 不上传数据
- 发布直出 EXE、源码包和 SHA256 校验文件
- 新源码包只包含 v2 源码和构建所需文件，不再混入旧 Launcher、旧 PowerShell 运行链路或 WinRAR SFX 脚本

本次已经把仓库里的旧 PowerShell 引擎、旧 Launcher、旧 rules 目录和自解压一键运行版打包脚本移除。后续发布只保留：

- GitHub 直出 EXE
- 透明 RAR
- 源码 RAR
- SHA256 校验文件

这个工具本身会扫描、备份和清理注册表、服务、计划任务、右键菜单、浏览器外部宿主和文件关联，所以被启发式规则识别成“系统工具/清理工具/潜在风险工具”是可能的。

建议处理方式：

1. 只从官方 GitHub Release 或本帖同步附件下载。
2. 优先下载 `RogueCleaner-v2.0.13-*.exe` 直出 EXE。
3. 用 `SHA256SUMS-v2.0.13-*.txt` 核对文件哈希。
4. 需要审查的用户下载源码包自行编译。
5. 如果仍然报毒，按误报提交给对应杀软厂商。

项目不会通过加壳、改壳、绕过杀软或隐藏行为来“解决”误报。
