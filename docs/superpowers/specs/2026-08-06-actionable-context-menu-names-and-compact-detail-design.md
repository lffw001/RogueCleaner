# 可操作右键菜单名称与紧凑详情栏设计

## 目标

扫描结果必须告诉用户具体会移除什么功能，同时缩小详情栏，优先保证左侧结果表的可读宽度。

## 名称规则

1. 注册表存在可读菜单文字时，直接显示该文字。
2. 没有菜单文字时，仅使用已验证的处理器名、CLSID 或模块名映射具体功能。
3. 动态生成子菜单但无法静态取得子项时，显示可确认的功能域，例如“WPS 云文档操作菜单”，不猜测具体子项。
4. 只能确认所属软件时，显示“软件名 + 右键扩展（具体功能未识别）”。禁止使用“相关菜单”一类含混名称。
5. 完整证据继续保留在详情和证据报告中。

## WPS 映射

- `qingshellext` / `{67F4D210-BFC2-4ADD-9A2A-C9B9E1F42C4F}`：上传到 WPS 云文档。
- `QingNseContextMenu` / `{AA147FFB-0B1F-4BB1-9B1E-8D062B35C146}`：WPS 云文档操作菜单。
- `kwpsshellext`：WPS Office 文档操作菜单。
- `knewdocshellext`：新建 WPS 文档菜单。
- `KingsoftOfficePDF.ContextMenu`：WPS PDF 操作菜单。
- `kpdf2wordshellext`：WPS PDF 转 Word。

## 详情栏

- 默认宽度由约 350 像素缩至 285 像素，最小宽度 250 像素。
- 减少内边距、标题高度、卡片间距和底部按钮高度。
- 详情内容保持纵向滚动，信息不删除；表格获得更多横向空间。
- UI 回归测试校验默认窗口下详情栏处于 250 到 300 像素之间。
