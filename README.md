# 流氓软件克星

本工具用于扫描并清理 Windows 上常见软件偷偷塞进系统里的右键菜单、自启动、计划任务、服务、浏览器插件、文件关联和卸载残留。

默认只扫描，不会偷偷清理。扫描结果默认一项都不勾选，要清理必须在 GUI 里手动勾选并确认。

作者：aakk007

- 吾爱破解：https://www.52pojie.cn/?286924
- GitHub：https://github.com/aakk007

主表优先显示“小白能判断的影响”，例如：

- 右键会出现：使用360解除占用 / 使用360强力删除 / 使用360管理右键菜单。
- 右键“打开方式”里会出现：百度网盘（影响 .mp4 文件）。
- 双击/打开 .doc 会交给：WPS 文字。
- WPS 会按计划自动检查/拉起更新。

注册表路径、服务名、任务名这类技术细节只作为“技术藏身位置”保留，不作为主要判断依据。

右键菜单、Windows 现代右键菜单、打开方式这些项目，鼠标停在“用户会看到/受到什么影响”列时，会弹出模拟右键菜单预览，尽量还原用户实际右键时会看到的菜单文字。

## 启动 GUI

普通用户优先使用“一键运行版”，下载后直接双击：

```text
流氓软件克星_一键运行版_YYYYMMDD-HHMMSS.exe
```

发布时使用带时间戳的一键版，避免本机资源管理器因为同名 EXE 缓存旧图标。

如果使用“EXE透明发布版”，需要先把发布包完整解压到一个文件夹，然后双击：

```text
流氓软件克星.exe
```

发布包采用透明目录结构，`RogueCleaner.ps1` 和 `rules` 会明文放在 exe 同目录，方便用户和杀软直接审查。双击只显示“流氓软件克星”的原生窗口，不会弹 PowerShell 窗口。

不要在 WinRAR/压缩包预览窗口里直接双击 exe，也不要只单独拖出 exe。这样只会临时解出 exe，旁边的脚本和规则跟不过去，程序会提示缺少文件。

“一键运行版”会自动解压完整运行文件到本机用户目录再启动，适合只想双击一个 EXE 的用户；“透明发布版”适合需要查看脚本和规则、排查杀软误报的用户。

源码调试时也可以直接跑脚本：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\RogueCleaner.ps1
```

如果要清理 HKLM、服务、计划任务等系统级项目，请在 GUI 中点击“管理员重开”。

## 命令行扫描

```powershell
.\流氓软件克星.exe -Scan -NoGui
```

脚本调试：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\RogueCleaner.ps1 -Scan -NoGui
```

扫描报告会写入：

```text
reports/
```

每次清理备份会写入：

```text
backups/
```

## 覆盖范围

默认覆盖：

- 360、2345、WPS/金山、百度/百度网盘、搜狗、迅雷、腾讯系、驱动工具、国产压缩工具、国产影音工具。
- 普通右键菜单和 Windows 11 现代右键扩展。
- 开机启动、启动文件夹、计划任务、服务。
- Chrome、Edge、Firefox 的外部扩展、强制扩展策略、Native Messaging Host。
- 图片、视频、压缩包、种子、下载合集、Office 文档等文件关联。

默认不扫描主程序卸载项，避免不懂的人把正常主程序当成“可清理项”误卸载。

## 风险等级

低风险：右键菜单、打开方式残留、卸载残留。

中风险：文件关联、开机启动、计划任务、浏览器插件。

高风险：服务、驱动服务、主程序卸载。

所有项目都不会默认勾选。高风险项需要用户手动勾选并确认。主程序卸载项默认不进入扫描结果。

需要批量选择时，可以点“勾选全部”，也可以点表头“选”来勾选/取消当前列表。

清理后会逐项复核并自动复扫。删除失败、权限不足、软件自保护或目标仍然存在时，不再假装清理完成，会直接提示失败/残留数量并保留在复扫列表里。

## 回滚

清理前会自动导出注册表、任务 XML、服务配置和被移动的文件。

恢复最近某个备份：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\RogueCleaner.ps1 -Restore -Backup .\backups\20260720-153500
```

## 设计原则

- 不联网。
- 不常驻后台。
- 不加壳。
- 不混淆。
- 不把脚本和规则 base64 内嵌进 exe。
- 不强行绕过软件自保护。
- 不改写 `UserChoice`。
- 不默认卸载主程序。
- 不删除用户文档。
- 先备份，再清理，清理后复扫。

## 当前限制

部分软件带自保护，普通权限下无法删除或禁用，需要管理员权限。

部分卸载器没有安静参数，工具会跳过，避免弹出安装器窗口。

Windows AppX 现代右键扩展第一版只报告，不直接拆包修改。

## 构建 exe

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Build-Exe.ps1
```

发布包会生成到：

```text
dist\流氓软件克星\
```

发布包里只需要双击 `流氓软件克星.exe`，不要直接操作源码里的 `.ps1`。

发布包内会包含 `RogueCleaner.ps1` 和 `rules` 目录，这是为了透明审查和降低启发式误报，不是多余文件。

`RogueCleaner.ps1` 在发布包里会写成 UTF-8 BOM，兼容 Windows PowerShell 5.1。没有 PowerShell 7 的 Win10/Win11 机器也能正常读取中文脚本。
