# GitHub Issue 反馈核对规范

适用于所有会改变扫描、识别、清理、恢复、界面或发布行为的代码修改。

## 每轮修改前

1. 只读获取 `aakk007/RogueCleaner` 的全部开放 Issue 和最近关闭 Issue 的正文、评论、标签及更新时间。
2. 对每一项记录“已覆盖”“待修复”“需要样本”或“不纳入当前架构”。
3. “已覆盖”必须指向代码位置或可重复的回归验证；不能因为标题相似就认定已解决。

## 修复判定

- 本轮涉及的问题，必须添加与 Issue 症状对应的验证。界面问题至少包含可视截图和自动边界检查。
- 需要真实机器样本、注册表项、路径、软件版本或检测报告的反馈，先请求或收集脱敏证据；不得根据描述直接扩大清理规则。
- 涉及安全软件误报时，保持不加壳、不混淆、不规避检测；保存文件哈希和检测信息，走厂商误报复核渠道。

## 公开沟通

代码与本地验证完成后，可以准备公开 Issue 回复草稿，但创建评论、关闭或重开 Issue、添加标签均须由用户明确授权。没有授权时，结论仅记录在本地验证文档。
