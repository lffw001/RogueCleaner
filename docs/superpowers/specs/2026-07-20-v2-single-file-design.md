# 流氓软件克星 v2.0.0 单文件开源版设计

日期：2026-07-20

## 目标

`v2.0.0` 是正式开源发布起点。目标是把现有 PowerShell 脚本版升级为 C# WinForms 单文件工具，解决高 DPI 卡顿、扫描慢、误操作恢复、版本更新、单文件发布和杀软误报解释困难这些问题。

最终发布物优先只有一个：

```text
流氓软件克星.exe
```

用户把 exe 放在哪里运行，工具就在同目录创建一个运行数据目录：

```text
流氓软件克星数据
```

主 exe 不搬家，不自复制，不静默安装，不创建多个散落目录。

## 发布和仓库

项目建立独立开源 GitHub 仓库，建议仓库名：

```text
https://github.com/aakk007/RogueCleaner
```

当前 `D:\Codex\Workspace` 的 Git remote 是 `aakk007/erp_demo.git`，不能把本工具提交到该 remote。实施时先在 `D:\Codex\Workspace\流氓软件克星` 初始化独立 Git 仓库，再设置新的 GitHub remote。

发布使用 GitHub Releases：

- `流氓软件克星.exe`
- 源码包
- SHA256 校验值
- 更新说明

## 技术路线

保留 C# WinForms 和 .NET Framework 4.x，重写扫描和清理核心到 C#。

不再依赖这些运行时 sidecar：

- `RogueCleaner.ps1`
- `rules\*.json`
- WinRAR SFX 自解压外壳
- base64 内嵌脚本

规则数据改为 C# 源码中的普通结构化数据，开源可审查。后续如果规则库明显变大，可以再拆成编译期资源，但不能运行时释放成散落文件。

## 运行目录

首次启动时创建：

```text
<exe 所在目录>\流氓软件克星数据
```

子目录：

```text
backups
reports
logs
updates
quarantine
state
```

用途：

- `backups`：注册表、任务、服务、文件移动前的恢复数据。
- `reports`：扫描报告、清理报告、复扫报告。
- `logs`：异常和诊断日志。
- `updates`：用户确认后下载的新版本文件。
- `quarantine`：被移动隔离的启动项、快捷方式或残留文件。
- `state`：首次运行标记、版本检查时间、用户设置。

工具不主动写 `%LOCALAPPDATA%`、`%TEMP%` 或其他目录。系统操作本身产生的 Windows 缓存不属于工具自建目录。

## 首次运行

首次运行显示一个轻量提示：

- 是否创建桌面快捷方式。
- 默认勾选创建。
- 用户可以取消。

快捷方式指向原始 exe 路径，不把 exe 移入数据目录。

如果运行环境缺少需要的 .NET Framework，主程序本身可能无法启动。发布页和 README 必须明确最低运行环境，并给出微软官方下载地址。后续可以增加原生小启动器，但不作为 v2.0.0 必做项。

## 扫描架构

扫描核心拆为多个扫描器：

- `ContextMenuScanner`：传统右键菜单、ShellEx、Windows 11 相关注册项。
- `StartupScanner`：Run、RunOnce、启动文件夹。
- `ScheduledTaskScanner`：计划任务。
- `ServiceScanner`：服务和驱动服务。
- `BrowserExtensionScanner`：Chrome、Edge、Firefox 外部扩展、Native Messaging Host、强制扩展策略。
- `FileAssociationScanner`：打开方式、ProgID、文件关联残留。
- `InstalledAppScanner`：默认关闭，只在用户明确开启时扫描可卸载主程序。
- `AppxScanner`：现代 AppX 右键扩展，默认只报告。

扫描输出统一为 `Finding`：

- `Id`
- `Risk`
- `Vendor`
- `Category`
- `UserVisibleName`
- `UserImpact`
- `TechnicalLocation`
- `ActionKind`
- `ActionTarget`
- `RequiresAdmin`
- `CanRestore`
- `Evidence`

UI 显示小白能理解的信息，技术路径放到详情和 tooltip。

## 多线程和性能

点击扫描后，UI 立即进入后台扫描，不阻塞窗口。

并发策略：

- 每个扫描器作为独立任务运行。
- 默认最大并发数为 `min(4, CPU 核心数)`。
- 注册表枚举类扫描器内部可以分 root 并行，但要限制并发，避免卡住系统。
- 计划任务、服务、AppX 这类系统 API 扫描器使用独立任务，不在 UI 线程执行。

UI 刷新策略：

- 先显示扫描进度和当前类别。
- 分批追加结果，例如每 100 条或每 200ms 刷新一次。
- DataGridView 使用虚拟模式或轻量绑定，避免大量行导致高 DPI 重排卡顿。
- 高 DPI 下固定行高，关闭不必要的自动换行重算，详情用侧栏/弹窗展示。

## 清理和复核

清理流程：

1. 用户勾选项目。
2. 二次确认，明确高风险数量和需要管理员权限数量。
3. 为每项写备份。
4. 执行清理动作。
5. 逐项复核目标是否真的消失或禁用。
6. 自动复扫。
7. UI 显示成功、失败、跳过、残留。

清理失败不能显示为完成。失败原因包括：

- 权限不足。
- 软件自保护。
- 目标被软件立即重建。
- 注册表/服务/任务路径已变化。
- 只报告项目没有清理动作。

失败项保留在复扫列表中，并显示具体原因。

## 恢复中心

新增“恢复中心”页面。

恢复中心按清理批次显示：

- 清理时间。
- 清理项目数量。
- 成功、失败、跳过数量。
- 涉及厂商。
- 备份路径。

支持：

- 恢复整次清理。
- 恢复单个项目。
- 查看清理报告。
- 查看恢复结果。

恢复动作也要写日志。恢复失败时提示原因，不覆盖用户已有的新状态，除非用户再次确认。

## 自动更新

采用提示式更新，不做静默更新。

启动后检查 GitHub Releases：

- 没有新版：不弹窗。
- 有新版：弹窗显示当前版本、新版本、更新说明、下载地址。
- 用户点击下载后打开 GitHub Release 页面或下载链接。
- 不后台静默下载 exe。
- 不偷偷替换当前运行中的 exe。

版本信息内置：

```text
ProductName = 流氓软件克星
Version = 2.0.0
Repository = https://github.com/aakk007/RogueCleaner
```

更新检查结果缓存到 `流氓软件克星数据\state`，避免每次启动都请求 GitHub。默认每天最多自动检查一次，界面提供手动“检查更新”。

## 单文件和杀软信任

v2.0.0 必须避免这些行为：

- 不加壳。
- 不混淆。
- 不把脚本 base64 内嵌后释放。
- 不使用 SFX 自解压。
- 不静默下载运行库或新 exe。
- 不后台常驻。
- 不安装服务。

可接受行为：

- 创建一个明确命名的数据目录。
- 写报告、备份、日志、隔离文件。
- 用户确认后打开 GitHub 下载页。
- 用户确认后创建桌面快捷方式。

发布说明必须写清工具会读取和修改注册表、计划任务、服务配置，因此安全软件仍可能提示风险；但源码、构建方式和规则都公开可审查。

## UI 改造

主界面保留现有风格，但优化高 DPI：

- 顶部标题和按钮不挤压。
- 表格行高固定。
- 长文本不在表格里无限换行，改为详情面板显示。
- 扫描进度按类别显示。
- 清理结果显示明确统计。

新增页面/入口：

- 扫描结果。
- 恢复中心。
- 设置。
- 关于/更新。

文案继续保留吐槽风格，但错误提示必须直说原因和下一步。

## 测试标准

最低测试：

- 构建单文件 exe。
- Win10/Win11 本机启动、扫描、清理、复扫。
- 人工创建 HKCU 测试右键项，清理后直接确认注册表不存在。
- 人工创建 OpenWith 测试值，清理后直接确认注册表值不存在。
- 人工构造失败项，确认 UI 不显示完成。
- 恢复中心恢复测试项。
- 高 DPI 200% 下启动、扫描、滚动不卡死。
- 没有外部 `RogueCleaner.ps1` 和 `rules` 依赖。
- 运行后只创建 `流氓软件克星数据` 一个目录。
- GitHub Release 版本检查无新版不弹窗，有新版弹提示。

发布前校验：

- SHA256 输出。
- 源码包包含构建脚本。
- README 写清运行环境、目录行为、恢复方式和误报解释。
