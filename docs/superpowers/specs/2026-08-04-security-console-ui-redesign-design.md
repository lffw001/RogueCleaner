# 安全工具控制台 UI 改版设计

## 1. 设计方向

采用参考方案一的浅色、克制、安全感主框架，并引入方案三的右侧证据详情面板。目标不是照搬火绒或 360，而是形成适合“启动项、右键、弹窗/流氓组件诊断”的原创 Windows 工具界面。

保持 C# WinForms、单 EXE、离线、不常驻，不增加杀毒、病毒扫描、云信誉或广告功能。本轮只改界面结构和交互呈现，不改变现有识别、清理、恢复和反馈安全边界。

## 2. 主窗口结构

窗口继续支持最小 `1120 × 700`，默认 `1280 × 780`，使用 DPI 自适应。整体分为四层：

1. 顶部标题栏：左侧显示产品名与版本；右侧依次为“检查更新”“反馈”“管理员状态”。“反馈”固定紧跟“检查更新”，本轮不新增空壳设置入口。
2. 主操作栏：左侧突出“开始扫描”和红色描边的“清理勾选”；其后为“勾选可清理”“只勾低风险”“恢复中心”“打开证据报告”等次级动作。
3. 左侧导航：总览、启动项、右键菜单、弹窗诊断、恢复中心。导航只切换当前结果筛选和视图，不重复扫描。
4. 内容工作区：上方状态卡片，中部结果列表，右侧证据详情面板，底部状态栏。

顶部不再放两行容易裁切的 FlowLayoutPanel。标题栏和操作栏使用明确的左右分区及溢出策略；窗口变窄时次级动作进入“更多”，主操作和“检查更新/反馈”始终可见。

## 3. 状态卡片与结果区

状态卡片固定为四项：建议处理、可管理、系统可信、未知。使用数字、短说明和低饱和状态色，不用大面积警告色制造恐慌。

结果表只保留决策所需的紧凑列：勾选、层级/风险、名称、厂商、来源、影响、操作。技术位置和长证据从表格移到右侧详情面板，从而在默认窗口宽度下避免主要内容依赖横向滚动。

搜索与筛选位于表格上方，支持层级、风险和来源。选择任意行后，详情面板立即更新；双击行只展开详情，不改变勾选状态。

## 4. 右侧详情面板

采用方案三的分区信息结构，默认宽度约 340–380 像素，可折叠。内容依次为：

- 项目标题、厂商、当前层级与风险。
- 身份依据：签名、Publisher、CompanyName、ProductName 等当前已有证据。
- 行为事实：启动、右键、服务、任务、弹窗/守护等可验证事实。
- 建议原因：为什么属于建议处理、可管理、系统可信或未知。
- 处理影响：执行后会禁用、删除入口、弹出卸载器还是仅报告。
- 技术位置与复制入口。

当前数据模型尚未完全拆出上述结构时，先按稳定分隔符和现有字段进行保守映射；无法可靠拆分的证据原文放在“更多证据”，不得凭 UI 文案重新推断身份或风险。

## 5. 反馈入口与反馈窗体

主窗口顶部右侧固定顺序为“检查更新 → 反馈”。结果行不再依赖最右侧、需要横向滚动才能看到的反馈按钮；顶部“反馈”默认关联当前选中项，没有选中项时可直接提交漏报。

反馈窗体与主窗口统一：白色内容区、青绿色主色、低饱和边框、清晰分组。布局为：

1. 顶部标题和隐私提示。
2. 四种反馈类型卡片：误报、漏报、身份错误、关联错误。
3. 用户说明输入区。
4. 可选 SHA256。
5. 脱敏预览区，敏感占位符用浅色强调。
6. 底部“仅保存本地”和“复制并打开 GitHub”。

反馈安全逻辑沿用现有实现，不在 UI 层绕过脱敏或直接提交 GitHub。

## 6. 视觉规范

- 背景：`#F5F7FA`；卡片：白色；主色：`#0F766E`；强调色：`#0D9488`。
- 危险动作仅使用红色描边或小面积红色，不使用整块高饱和红背景。
- 字体使用 Microsoft YaHei UI；标题、数字、正文建立明确字号层级。
- 圆角控制在 4–6 像素等效视觉；WinForms 无需引入第三方 UI 框架。
- 图标优先使用简单线性矢量/程序绘制符号，不使用品牌 Logo、盾牌或杀毒图标。
- 表格使用 36–40 像素行高、弱分隔线、状态圆点/标签，选中态使用浅青色背景。

## 7. 源码边界

新增独立 UI 辅助源码，集中管理颜色、字体、按钮、卡片和布局工具；主窗体只负责组合控件和绑定事件。反馈服务与脱敏逻辑保持在现有 `FeedbackFeature.cs`，只调整反馈窗体呈现。

不在本轮重写扫描器，不修改厂商识别规则，不修改清理动作真值表，不引入第三方 NuGet 依赖。

## 8. 验收标准

- 默认窗口和最小窗口下，“开始扫描”“清理勾选”“检查更新”“反馈”始终完整可见。
- “反馈”位于“检查更新”之后；有选中项时关联该项，无选中项时可反馈漏报。
- 默认宽度下，主结果区不依赖横向滚动即可看清名称、厂商、来源、影响和操作。
- 选中行后详情面板正确显示现有数据，不重新推断厂商或风险。
- 反馈窗体不存在控件重叠、文字裁切或按钮越界，脱敏预览与现有自测保持通过。
- 100%、125%、150%、200% DPI 下核心按钮和详情面板边界不互相遮挡。
- 普通构建、反馈脱敏、身份碰撞和真实扫描烟测通过；清理/恢复行为无回归。
- 最终仍为单 EXE，发布目录不增加运行时依赖。
